# 05 - Support Group Tags and Tag-Based Splits

**What to build:** Participants can create Group-level Tags and use them to charge only selected Participants on tagged Expenses.

**Blocked by:** 04 - Support Manual Amount and Percentage Splits.

**Status:** ready-for-agent

- [ ] Participants can create Tags scoped to a Group.
- [ ] Participants can view the Tags for a Group.
- [ ] A tagged Expense charges only the selected Participants for that Tag.
- [ ] Tag-based Splits produce correct Balances.
- [ ] Tags from one Group cannot be used in another Group.
- [ ] The Group detail view supports creating and selecting Tags for an Expense.
- [ ] OpenAPI documents Tag routes and Tag-based Split inputs.
- [ ] Backend tests cover Tag scope, Tag membership, and Balance effects.
- [ ] Frontend tests cover Tag creation and Tag-based Expense creation.
